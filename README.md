# ml

Empty Unity 6 3D project bootstrap with Universal Render Pipeline (URP).

## Open

1. Clone the repository and switch to `unity-urp-bootstrap`.
2. In Unity Hub, add the repository folder as a project.
3. Open it with Unity 6. Unity will resolve packages and generate the remaining local project files.
4. Create the first scene and save it under `Assets/Scenes`.

The repository excludes generated Unity folders such as `Library`, `Temp`, `Obj`, `Build`, and IDE files.
